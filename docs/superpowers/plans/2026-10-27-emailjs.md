# EmailJS Integration Implementation Plan

**Goal:** Send the two existing B2B forms through EmailJS while preserving static hosting and WhatsApp/WeChat alternatives.
**Architecture:** Generate one allowlisted public JSON contract using Next's environment loader. Validate and cache it in the browser; map validated form data to string-only typed email parameters. Keep recipients entirely in dashboard settings.
**Tech stack:** Next.js 16.4.3 static export, React, TypeScript, official EmailJS browser SDK, Node test runner, Playwright.
**Spec:** User attachment, “GANLAN GOLD — COMPLETE EMAILJS INTEGRATION”. Execution is directly authorized by that specification.

## Constraints
- Keep Chinese default, UI, contacts, global 7,500 L policy, prices, images, animations and SEO.
- No server, API routes, database, SMTP secrets, arbitrary recipients or real test emails.
- Production builds must reject missing credentials. An explicitly named preview build may export a disabled-mail site for review.
